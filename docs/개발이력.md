### 오케스트레이션 반영 현황

#### 반영 완료

- `apps/api/src/synthetic_api/application/services/job_runtime.py`를 추가해 장시간 작업의 진행 상태, 종료 상태, 취소 신호를 공통화했습니다.
- 단일 합성과 일괄 처리가 공통 작업 상태와 진행률 저장 콜백을 사용하도록 연결했습니다.
- 작업 저장소와 API 이력 조회를 기준으로 작업 상태를 확인할 수 있도록 구성했습니다.
- 화면의 푸터 `개발이력`에서 개발이력, 라이브러리목록, 프로젝트안내, 아키텍처 문서를 검색·목차·원문 보기로 확인할 수 있습니다.

#### 아직 남은 작업

- 현재 작업 런타임은 프로세스 내부 메모리와 스레드를 사용합니다.
- 외부 오케스트레이터의 workflow ID 연동, 내구성 있는 큐, DB 기반 취소 플래그 전환은 설계·개선 목록 단계입니다.
- 설문 작업의 공통 DB 작업 모델 통합과 파이프라인 단계별 재시도·타임아웃 분리는 후속 작업입니다.

  - `PyMuPDF` + `pdfplumber` 하이브리드 시맨틱 레이아웃 분석기 탑재 (상단 배너, 안내 박스, 섹션 제목, 상담 카드 UI, 다중 열 표 정밀 분리)
  - **HTML**: 배너 다크블루(`#1a365d`), 안내 박스, 카드 테두리, 표 헤더(`#edf2f6`) 및 셀 병합(`colspan="3"`) 1:1 시각적 재현

- 비정형 문서 파일(PDF, 한글 HWP/HWPX, 워드 DOCX/DOC, 마크다운 MD) 구조화 파싱 및 가명처리 파이프라인 통합
- 18종 한국형 개인식별정보(PII) 형식 보존형 스마트 부분 마스킹(주민등록번호 성별 보존, 전화번호 중간 마스킹 등) 구현
- 문서 본문 및 복합 텍스트 내 인라인(Inline) 개인정보 자동 탐지 및 일괄 가명처리 지원
- 가명처리 스튜디오 결과 화면(Before vs After) 마스킹 변경값 강조 표시 UI 개선
