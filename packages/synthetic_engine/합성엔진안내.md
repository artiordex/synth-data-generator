# 합성 엔진 패키지

`packages/synthetic_engine`은 정형·관계형·시계열 데이터를 합성하고, 품질·프라이버시 지표를 계산하는 핵심 Python 패키지입니다.

## 주요 책임

- 입력 데이터 프로파일링과 자료형·결측값 정리
- 통계 기반, CTGAN, TVAE, Gaussian Copula 합성
- 관계형 데이터의 키 제약과 시계열 순서 보존
- 가명처리, 차분 프라이버시, k/l/t 위험도 평가
- 분포·상관·재식별 위험 분석 결과 생성
- CSV, Excel, Parquet, HWPX, Markdown 등 산출물 내보내기

## 실행

저장소 루트에서 다음 명령으로 패키지 테스트를 실행합니다.

```powershell
uv run --locked --all-packages python -m pytest packages/synthetic_engine/tests
```

합성 실행의 API 진입점은 `apps/api`이며, 엔진 내부 모듈을 직접 호출하기보다 API 서비스와 공통 계약을 사용합니다.
